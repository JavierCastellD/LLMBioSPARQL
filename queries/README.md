# queries/

This folder contains example question–answer pairs used to develop, instruct, and evaluate the Text2SPARQL pipeline, as well as complex reference use-cases.

Each JSON file shares the same schema:

```json
{
  "question": "Natural-language question",
  "graphs": {
    "entity_graphs":   ["graph names needed for entity lookup"],
    "relation_graphs": ["graph names needed for relationships"]
  },
  "extracted": {
    "entities":      ["..."],
    "output":        ["..."],
    "relationships": [{"subject": "...", "predicate": "...", "object": "..."}]
  },
  "sparql": "SELECT ..."
}
```

---

## Files

### `examples_simple.json`
9 single-hop questions created by **Javier Granda** for his master's thesis. These were used as the few-shot examples that instruct the LLM (i.e. they appear directly in the system prompt). They cover basic lookups on single BioGateway named graphs: gene properties (label, definition, position, chromosome, close matches, synonyms) and gene–protein encoding.

### `examples_extended.json`
15 questions generated by **Claude Sonnet 4.6**, using `examples_simple.json` as a template and the UC use-case files (see below) as thematic inspiration. They extend coverage to multi-hop queries involving proteins, enhancers, transcription factors, diseases, GO terms (biological process, molecular function, cellular component), and orthology.

### `examples_ft_Javi.json`
~50 questions used by **Javier Granda** in his master's thesis to fine-tune a Llama model. These questions are more complex and biomedically richer than the simple set. The `extracted` and `sparql` fields are intentionally empty — the corresponding ground-truth SPARQL queries are not available.

### `test_examples.json`
Held-out evaluation set. Contains all entries from `examples_simple.json` and `examples_extended.json` that are **not** part of the system prompt, so they were never seen by the model during prompting. Use this file to measure extraction quality without in-context contamination. 16 entries total (5 from simple, 11 from extended).

## Use-cases (UC files)

Complex, multi-step SPARQL queries designed by **Juan Mulero** to illustrate realistic biomedical research workflows on BioGateway. They serve as the upper bound of difficulty for the pipeline and are not yet handled end-to-end.

| File | Topic |
|---|---|
| `UC1.txt` | Impact of a SNP (rs4784227 / chr16:52565276) on gene-expression regulation: enhancers, target genes, proteins, biological processes, TFs |
| `UC2.txt` | Regulatory landscape of breast cancer: phenotype-linked genes, enhancers in breast tissue, biological processes, cooperating TFs |
| `UC3.txt` | Dataset generation linking OMIM phenotypes, genes, CRM enhancers (with coordinates and distances), proteins, GO terms, protein interactions, and TF regulation |
